This project contains everything you need to run your app locally.
Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the right environment variables

This matches the Royal Conservatory Of Music's ear training requirments with practice for you. It is compatible with the piano and guitar. It is very unpolished, and has some rough patches, it could use some debugging in places. Please feel free to edit and enjoy.
